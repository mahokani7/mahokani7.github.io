# 개요

"좋은 응답"이라는 모호한 판단을 8개의 측정 가능한 축으로 나눴습니다. 각 축마다 루브릭을 정의하고, Judge 모델이 점수와 근거를 JSON으로 반환하도록 프롬프트를 설계해, 사람 평가자 없이도 재현 가능한 품질 스코어를 산출합니다.

# 설계 산출물

지표 체계
8축 정의 및 축별 판정 기준(루브릭)
Judge 프롬프트
축별 점수 + 근거를 담는 JSON 출력 스키마
집계
축별 스코어 → 종합 품질 지표로 환산

# 활용

  • VOC QA 파이프라인(PRJ_01)·AI 품질 플랫폼(PRJ_02)의 평가 코어로 재사용
  • 회귀 감지: 배포 전후 축별 점수 비교로 품질 저하 조기 탐지
  • ISO/IEC 25010 품질 특성과 지표 매핑 가능
