# 개요

고객의 소리(VOC)를 여러 전문 에이전트가 분업 처리하는 멀티에이전트 구조에서, 산출물의 품질을 사람이 일일이 검수하는 병목을 제거하는 것이 목표였습니다. LLM-as-a-Judge를 도입해 응답의 관련성·정확성·근거성 등을 자동 평가하고, 결과를 리포팅 대시보드로 집계했습니다.

# 담당 역할

테스트 설계
평가 시나리오·기준(루브릭) 정의, Judge 프롬프트 검증
발표
최종 발표 PPT 스크립트(합니다체, 10분) 작성 및 시연(OBS 녹화)
협업
나병진(환경/PM)·김경숙(핵심개발)·정진웅(리포팅) 협업

  • 8개 지표 기반 정량 스코어로 개선 우선순위 도출
